There is a simpler way to create amazing layouts: invisible grids.

Gridless is a CSS framework that ships with no source code. Instead, it is built on a set of strong principles. The basic Gridless rules:

1. Every element size is divisible by 10 pixels.
2. Use only pixels as a unit.
3. Every parent element is a block (forms, images, and so on).
4. Inline elements must be text based (strong, em, span).
5. Never use 1-pixel borders.
6. Use 2-pixel borders or a background color instead.
7. Reset to zero (padding, margin, width, height, and so on).
8. Use a base line-height of 20px, then increase each step by 10px.
9. Design at 1x, then multiply by 2x, 3x, or 4x.

The problem with current grid systems is that they are too restrictive. You can see the columns when they work — and the mismatches when they don't.

The problem with CSS frameworks is that they are too complex to learn, let alone understand at a deeper level.

Gridless solves both problems. It is a foundation you can build anything on.
