The future happens when you take radical decisions. When you say stop and start over. When you say it is time to move on. When you say you need a change. When you say you want different things. When you want a different job.

#### Engineering

The main problem designers face today is that anyone can create a design. I noticed this trend a few years ago, back when I was a pretty good designer myself. Then I decided to re-learn programming. I built [Subreply](https://subreply.com) and now I work full-time as a software engineer. I still think design beats code, but it is hard to explain to someone why one design is better than another. With code it is easier: it either does what the end user is asking or it does not. Working as a software engineer is challenging, to say the least. If you like puzzles, you will enjoy a good coding session. But if you find a puzzle boring, you need to figure out what is wrong with the puzzle in the first place. Then you create a loop for yourself to get into and achieve things.

#### The 4-inch iPhone

Eight days from now, Apple will unveil its new 4-inch iPhone, and I can't wait. My iPhone 4S is four and a half years old. It still keeps up with the newest software, but it fails at basic things like reading books. What I want from the new iPhone is a better display with a higher contrast ratio, just like the one on the iPhone 6/6s. The rest of the phone doesn't matter because I'll get used to it. I'm a creature of habit.
