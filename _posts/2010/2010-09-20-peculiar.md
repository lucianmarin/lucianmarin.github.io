I always forget that more than a hundred people read this particular blog, and that even more people know this site because of [The Journalist](https://github.com/lucianmarin/wp-journalist) — a theme created for WordPress years ago and still popular in this day and age of the Internet. Knowing there are people out there interested in what I do makes me want to write here. The problem with blogging (or any other activity) is that it brings back that peculiar feeling of restlessness. I'm a restless person myself, and young, but I can't stand the feeling of being restless. It makes me ignore the important things I want to do, create, design, achieve, believe — and so on, until I don't believe in anything anymore. It's a virtuous circle followed by a vicious circle.

**![Peculiar](/images/peculiar-up.png)**

Last month I started working on a different kind of project, namely [Peculiar](/2010/peculiar.html) — an icon package made only in CSS, with the purpose of helping designers create user interfaces for the web without using software programs, and helping developers achieve as few HTTP requests as possible, thus speeding up web applications. It is a challenge for me, and for anyone interested in the future of user interfaces for the web, to make use of CSS as intelligently as possible — creating designs in Adobe Photoshop, slicing images and putting them in as CSS backgrounds doesn't make [a lot of sense anymore](http://jasonsantamaria.com/articles/a-real-web-design-application/).

**![Peculiar](/images/peculiar-down.png)**

*After all that being said, he wants to change the things we are accustomed to for the (worst) better.*
